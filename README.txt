HAIR BY NASTIA — WEBSITE REDESIGN CONCEPT

Files:
- index.html: website structure and content
- styles.css: responsive visual design
- script.js: mobile navigation and current year

Preview locally: double-click index.html or open it in a browser.

Publish on GitHub Pages:
1. Create a public GitHub repository named hair-by-nastia-demo.
2. Upload index.html, styles.css, script.js and this README file.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select main and /(root), then Save.
6. Your URL will be https://YOUR-USERNAME.github.io/hair-by-nastia-demo/

IMPORTANT BEFORE CLIENT APPROVAL / OFFICIAL LAUNCH:
- This is an independent website concept, not the salon's official website.
- Stock photography is illustrative and must be replaced by owner-approved salon photos before official launch.
- Verify service list, prices, opening hours, booking method and contact details with the owner.
- No phone number or email has been invented. The current directions link opens Google Maps.
- Check image licensing and replace images with properly licensed or owner-provided images before commercial delivery.
